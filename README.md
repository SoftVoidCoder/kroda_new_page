# kroda_new_page

Адаптивный сайт КОРДА по предоставленному техническому заданию и фирменному гайдбуку. В проект входят главная страница, карточка кабеля GWS и серверная обработка заявок.

## Локальный запуск

```bash
PORT=4173 python3 server.py
```

После запуска сайт доступен по адресу `http://localhost:4173`.

Карточка товара: `http://localhost:4173/product.html`.
