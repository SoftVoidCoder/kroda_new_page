# kroda_new_page

Адаптивный сайт КОРДА по предоставленному техническому заданию и фирменному гайдбуку. Главная страница включает карточку кабеля GWS, характеристики и области применения. Раздел промышленного электрообогрева содержит отдельные страницы для малых промышленных объектов, оборудования и пластиковых ёмкостей. Формы обрабатываются сервером.

## Локальный запуск

```bash
PORT=4173 python3 server.py
```

После запуска сайт доступен по адресу `http://localhost:4173`.
