# kroda_new_page

Адаптивная одностраничная главная КОРДА по предоставленному техническому заданию и фирменному гайдбуку. Все блоки, включая карточку кабеля GWS, характеристики и области применения, собраны в одно полотно. Формы обрабатываются сервером.

## Локальный запуск

```bash
PORT=4173 python3 server.py
```

После запуска сайт доступен по адресу `http://localhost:4173`.
